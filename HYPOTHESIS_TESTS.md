# Эволюционные гипотезы: дополнительные проверки

Ветка `feature/origin-hypothesis-tests` содержит реальные **предварительные скрининги**:
- de novo: локальная синтения по двум соседним ДНК-участкам у как минимум двух видов и совпадение с участками без *аннотированного* CDS; требуется дополнительная проверка предкового ORF, дерева видов, скрытых белковых гомологов;
- дупликация: поиск дополнительных неперекрывающихся ДНК-локусов **в целевом геноме**;
- транспозиция: поиск сходной последовательности вне области, ограниченной коллинеарными фланками;
- древнее происхождение: межвидовая ДНК-гомология, перекрытие CDS, синтенные кодирующие совпадения;
- другие механизмы: статус `not_assessed`, пока нет отдельной специфической проверки;
- неопределённость: существенный ненулевой вес.

Для анализа синтении автоматически скачивается также **референсный геном исходного вида**. Два фланкирующих участка (по 4000 нуклеотидов) выравниваются отдельно на геномы родственных видов. Синтения здесь приблизительная и **не доказывает ортологию**.

**Важно:** отсутствующая CDS-аннотация != реально некодирующая последовательность. Проценты **не являются вероятностями** и не откалиброваны по известным происхождениям. Результат `preliminary_candidate` означает гипотезу для дальнейшего подтверждения, а не доказательство. Отсутствие результата не означает, что гипотеза исключена.
