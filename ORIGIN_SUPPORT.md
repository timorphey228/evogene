# EvoGene — распределение поддержки гипотез

После анализа генома система показывает **одну сводную таблицу и диаграмму** для шести вариантов:
de novo, дупликация, транспозиция/ретротранспозиция, древнее сохранённое происхождение,
другой механизм и недостаточно данных.

Сумма равна 100.0%. Это **нормированные веса свидетельств, не статистические вероятности**;
без обучающей выборки и калибровки категорически нельзя называть их шансом происхождения.
Ноль для механизма означает отсутствие диагностических данных, а не его исключение.
Текущий ДНК-поиск по сборкам не проверяет условия de novo и транспозиции, поэтому их
поддержка будет нулевой независимо от сходства. Дупликация требует выявленных
дополнительных локусов в целевом геноме; в режиме Auto NCBI это пока не проверяется.

Запуск на Mac:

```bash
cd ~/Desktop/evogene
git fetch origin
git switch feature/origin-support-summary
source .venv/bin/activate
python -m streamlit run auto_app.py
```

Результат виден в браузере; JSON содержит `origin_support.options`.
Для научной оценки нужны проверка синтении, гомология белков, дерево генов,
калибровка на размеченных примерах.
